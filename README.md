## 📖 项目简介
本项目**纯原生前端无框架、零第三方重型库**，1:1视觉&交互复刻超星学习通PC+移动端全核心业务，摒弃新手堆砌代码陋习，以工程化规范拆分目录、模块化管理样式与逻辑，是一套面向前端进阶实战的商用级页面复刻项目。
项目不做商用开发，仅用于前端DOM、布局、交互、工程化思维深度学习，高度还原学习通：首页、课程、作业、签到、在线考试、个人中心六大核心业务场景。

## ⚙️ 技术栈
- 基础：`HTML5语义化标签 + CSS3(Flex+Grid混合响应式) + 原生JavaScript ES6`
- 辅助：Font-Awesome图标、CSS3动画、localStorage本地存储模拟登录状态
- 数据：纯前端Mock模拟后端接口，无需对接真实服务即可完整跑通全业务

## ✨ 核心复刻功能（对标正版学习通）
1. **首页专区**：顶部轮播校园公告、已选课程卡片瀑布流、应用快捷导航（签到/作业/图书馆/网盘）、系统消息弹窗
2. **课程专区**：课程章节目录展开收起、课件预览、课程讨论区、附件资料下载模拟
3. **作业专区**：待提交/已批阅/逾期作业分类筛选、在线富文本填写作业、提交弹窗
4. **签到专区**：复刻4种签到UI：普通签到、二维码签到、手势签到、位置签到交互动画
5. **在线考试**：单选/多选/判断题型动态渲染、选项选中动效、试卷倒计时、提交防重复校验
6. **个人中心**：头像预览、个人信息编辑、历史成绩统计、我的收藏课程、已完成作业归档
7. **全端适配**：一套代码自适应PC端、平板、手机端，和官方学习通响应式规则一致

## 💥 项目硬核亮点（牛逼核心，区别于普通垃圾仿写项目）
### 1. 原生JS模块化编程，拒绝代码堆砌
不用Vue/React/JQuery，基于ES6 `class`、模块化思想拆分业务逻辑，签到、考试、作业各自封装独立类，代码高内聚低耦合，可无缝抽离组件复用，贴近企业前端工程开发思想。

### 2. 高保真像素级还原官方UI
严格对标超星学习通官方设计规范：主题色、圆角、间距、阴影、动效参数全部对齐原版，hover过渡、弹窗弹出、卡片展开全部使用原生CSS3动画，复刻APP级细腻交互。

### 3. 自建完整Mock业务中台
内置整套学习通业务数据库：数千条模拟课程数据、考试题库、作业数据、学生成绩，完全模拟后端返回JSON格式，后续接入真实后端时，仅替换接口地址即可全量上线。

### 4. 原生实现简易状态存储
使用`localStorage`模拟用户登录态、已做试题缓存、作业草稿保存，关闭页面再次打开数据不丢失，实现真实产品的本地缓存逻辑。

### 5. 可一键云端部署上线
项目全静态资源，可直接上传至：Github Pages / Gitee Pages / Vercel / Netlify，一键生成公网在线访问链接，分享即可在任意设备打开你的复刻学习通。
